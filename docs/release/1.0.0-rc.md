The month-end projection is labeled "weighted_avg_7d", but it adds the planned per-day allocation (weekday and weekend amounts) for the remaining days, not the 7-day average of actual spend. So a 10x spike changes neither the projected month-end figure nor the status derived from it (`forecastStatus`). The 7-day average is still computed and displayed, and it feeds "days until breach". Spend history feeds the confidence interval. Owner decision.
